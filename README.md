# labinett – Nikolo-Scheibe auswerten

Windows-Programm mit Web-Bedienung: Eine USB-Webcam erkennt aufgelegte Nikolo-Scheiben, nimmt automatisch auf, sobald die Karte ruhig liegt, zählt pro Schuss alle berührten Felder und speichert die Ergebnisse in einer CSV-Datei.
